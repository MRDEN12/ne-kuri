# 🚭 «Не курю» — Telegram Mini App: архитектура

> Трекер отказа от никотина: счётчик, лимит стиков IQOS, план снижения до нуля, статистика и SOS-поддержка.
> Всё в **одном статичном HTML-файле**, данные — в облаке Telegram. Бэкенда нет.

---

## 1. Что это

Telegram Mini App (WebApp), который открывается кнопкой в чате с ботом.
Назначение: Ваня бросает никотин (после солевого вейпа, стартовая доза ~90 мг/день, переход на IQOS).
Приложение помогает **считать стики, держать лимит, снижать по плану до нуля и переживать тягу**.

---

## 2. Запуск и хостинг

- **Тип:** Telegram Mini App (`telegram-web-app.js`).
- **Хостинг:** GitHub Pages (статика, HTTPS, бесплатно).
  - URL: `https://mrden12.github.io/ne-kuri/`
  - Репо: `github.com/MRDEN12/ne-kuri` (ветка `main`, корень).
- **Запуск в Telegram:** кнопка меню бота (Bot API `setChatMenuButton` с `type:"web_app"`) либо inline-кнопка `web_app` в приватном чате.
- **Данные:** Telegram `CloudStorage` (per-user, синхронизируется между устройствами) + fallback на `localStorage` (если открыто в браузере).
- **Бэкенда нет.** Внешних зависимостей нет, кроме официального SDK Telegram.

## 4. Слой данных

Единый объект `state`, сериализуется в JSON.

- Ключ CloudStorage: `nk_state`
- Ключ localStorage (fallback): `nk_state`

### Схема `state`

```jsonc
{
  "v": 1,                         // версия схемы (для будущих миграций)
  "startDate": "2026-09-25",      // дата старта плана (YYYY-MM-DD)
  "quitDate": null,               // дата полного отказа, или null
  "plan": {
    "startLimit": 20,             // стартовый лимит, стиков/день
    "step": 2,                    // на сколько снижать
    "everyDays": 7                // каждые сколько дней
  },
  "manualLimit": {},              // { "2026-10-01": 15 } — ручной лимит на конкретный день
  "log": {                        // { дата: [timestamp1, timestamp2, ...] } — каждый стик = отметка времени
    "2026-09-25": [1758770000000, 1758780000000]
  },
  "cravings": [                   // лог тяг (последние 200)
    { "t": 1758770000000, "i": 2, "n": "" }   // i: 1–3 интенсивность, n: заметка
  ],
  "settings": {
    "pricePerStick": 38,          // цена 1 стика, ₸
    "cur": "₸",
    "oldDaily": 90                // прежняя дневная доза никотина, мг (для справки)
  }
}
```

### Функции слоя
- `load(cb)` — читает CloudStorage (или localStorage), мержит в `DEFAULT`, вызывает `cb`.
- `save()` — пишет JSON в CloudStorage (и в localStorage как копию).
- `merge(obj)` — заполняет пропущенные поля дефолтами (защита от старых версий схемы).

## 5. Домен (чистые функции, без UI)

| Функция | Возврат | Смысл |
|---|---|---|
| `limitFor(dateStr)` | `int` | Лимит стиков на дату: ручной из `manualLimit`, иначе `startLimit − floor(деньПлана/everyDays)×step`, пол `0`; после `quitDate` = `0` |
| `currentLimit()` | `int` | `limitFor(сегодня)` |
| `smokedOn(dateStr)` | `int` | Сколько стиков записано на дату (`log[дата].length`) |
| `nextStep()` | `{date,limit}\|null` | Ближайший день, когда лимит падает |
| `zeroDate()` | `dateStr\|null` | Когда по плану лимит станет `0` |
| `streakUnderLimit()` | `int` | Подряд дней (до сегодня) с `smoked ≤ limit` |
| `daysFree()` | `int` | Дней подряд без никотина (считается только если после `quitDate` реально 0) |
| `total()` | `int` | Всего стиков за всё время |
| `avg7()` | `float` | Среднее стиков/день за 7 дней |
| `spent7()` | `float` | Потрачено за 7 дней (₸) |
| `savedTotal()` | `float` | Экономия: (сумма плановых лимитов за прош. дни − факт) × цена |

Утилиты: `today()`, `parseD()`, `fmtD()`, `diffDays()`, `human()` (DD.MM.YYYY), `pad()`.

---

## 6. Действия (меняют `state` → `save()` → `render()`)

| Функция | Что делает |
|---|---|
| `addStick(+1)` / `addStick(-1)` | Добавить/отменить стик сегодня (пишет/убирает timestamp в `log[сегодня]`), haptic, тост при превышении лимита |
| `logCraving(intensity)` | Пишет тягу в `cravings` |
| `saveSettings()` | Считывает поля из формы настроек, пишет в `state`, сбрасывает `manualLimit` |
| `copyReport()` | Собирает текстовый отчёт и копирует в буфер (чтобы переслать Оскару) |
| `startSos(sec)` | Запускает обратный таймер передышки (120/300 с) |
| `toast(msg)` | Всплывающее уведомление |
| `haptic(type)` | Вибро-отклик (`impactOccurred`) |

## 7. Экраны (табы, нижняя навигация)

1. **📆 Сегодня** — большой счётчик `выкурено / лимит`, прогресс-бар, кнопки `+1 стик` / `−1 (отмена)`, время последнего стика, мини-метрики (ряд под лимитом, средн./день, экономия).
   - Если `daysFree()>0` — экран переключается в режим «N дней без никотина» (герой-счётчик).
2. **📉 План** — текущий лимит, прогресс к нулю (%), следующее снижение, плановая дата «ноль», таблица графика снижения (шаги через `everyDays`).
3. **📊 Стата** — бар-чарт за 7 дней (стики vs лимит, превышение красным), метрики (всего/средн./потрачено/сэкономлено), достижения-бейджи (1/3/7/14/30 дн под лимитом, 1 дн / неделя без никотина), кнопка «Скопировать отчёт».
4. **🆘 SOS** — таймер передышки 5/2 мин, чек-лист «что сделать сейчас» (вода, дыхание 4-7-8, прогулка, занять рот, убрать IQOS), кнопки «Пережил тягу» / «Было тяжело», список последних тяг, поддерживающий текст.
5. **⚙️ Настройки** — скрытый таб (открывается шестерёнкой в шапке): дата старта, дата «ноль», стартовый лимит, шаг, период, цена стика; кнопка сброса.

## 8. UI / тема

- CSS-переменные в `:root`: `--bg --card --card2 --line --txt --dim --acc --acc2 --warn --bad --blue`.
- Можно подхватывать нативные параметры Telegram: `--tg-theme-bg-color` и т.д. (`TG.themeParams`) — тогда приложение подстроится под тему клиента.
- Mobile-first, `viewport-fit=cover`, `env(safe-area-inset-bottom)` для навбара.
- Шрифты системные, крупные тап-зоны (мин. 44px), haptic-фидбек.

## 9. Контракты для редизайна (НЕ ломать)

1. **Ключ CloudStorage:** `nk_state` (иначе данные «потеряются»).
2. **Схема `state`:** сохранить поля и типы; при изменениях — поднять `v` и добавить миграцию в `merge()`.
3. **Имена и поведение функций** §5–§6 — оставить (или обновить все вызовы).
4. **Отсутствие бэкенда:** только статика + Telegram SDK. Никаких секретов в коде.
5. **Размер и офлайн:** всё работает без сети, кроме загрузки SDK.
6. Допустимо: разнести на 3 файла, переписать CSS/вёрстку, добавить анимации, скелетоны, иконки (инлайн-SVG).
